# 找资料规范

## 1. 定位顺序

1. **根导航**：按主题找到对应分区。
2. **分区 README**：按文件说明选出候选文件。
3. **关键词搜索**：在候选目录里搜关键词。没有命中时换同义词、简称、英文名或相关术语。
4. **扩大范围**：仍然没有结果时，再搜索整个知识库，并跳过导航标明“不作为知识来源”的目录。
5. **对话资产**：问题涉及之前的讨论时，再用脚本搜索 `对话资产/`。

## 2. 读取

- 先看搜索命中的片段，确认相关后再读前后文。
- 长文件按小标题定位，只读回答需要的部分。
- 图片、PDF、音视频按宿主工具的能力读取。读不了时说明，不猜内容。

## 3. 回答格式

- 先给答案，再给依据。
- 依据写成 `路径` 加小标题或行号，宿主支持时用可点击链接。
- 标明资料类型，例如原文、转写、精编、笔记、AI 整理、实践产出。
- 多份资料说法不同时，列出各自的说法和路径。按版本规则说明以哪份为准；没有规则时让用户判断。
- AI 根据资料推断的内容，写明“这是推断”。

## 4. 找不到时

告诉用户：

- 搜过哪些目录
- 用过哪些关键词
- 有没有相近但不完全对应的内容

不用常识或网络信息冒充资料原文。需要查外部信息时先问用户。
